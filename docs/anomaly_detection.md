# Retail Anomaly Detection

An anomaly is an observation that differs substantially from
an expected or normal pattern.

Forecast-based anomaly detection can compare actual revenue
with model-predicted revenue.

The residual is the difference between actual and predicted
values.

A standardized residual, such as a residual z-score, can be
used to identify observations that are unusually far from the
model expectation.

An anomaly indicates that an observation differs from the
expected pattern. It does not automatically identify the
reason for the anomaly.

Root-cause analysis should examine additional evidence such as
categories, brands, cities, channels, inventory and pricing.

Detected relationships should be treated as associated signals
unless causal evidence is available.
